# Case Study: The Return Window

## LumaHome Online's Returns Problem

On a Tuesday morning in May, LumaHome Online's Chief Operations Officer, Elena Hartmann, stood in the return center outside Leipzig and watched a conveyor belt deliver three different versions of the same problem.

The first parcel contained a pair of shoes in perfect condition. It could be restocked quickly if someone inspected it today. The second contained a coffee machine with an unclear defect note and no customer photo. It needed a technical check. The third contained a dress from a promotional campaign that had already ended. It was sellable, but every day in the inspection queue reduced its resale value.

LumaHome's customer promise was simple: easy ordering, easy returns, quick refunds. The operating reality was more difficult. Returns arrived unevenly after promotions, holidays, and seasonal campaigns. Apparel and footwear generated high return rates because customers ordered multiple sizes. Electronics had lower return rates, but a delayed technical inspection could destroy recovery value. Home living products were expensive to handle. Some returns could be resold as new, some needed outlet markdowns, some required refurbishment, and some should never have entered the returns network at all.

The problem was not that returns were unexpected. Returns were part of the e-commerce business model. The problem was that LumaHome did not know where to intervene first.

## Company Background

LumaHome Online is a fictional European e-commerce retailer with central fulfillment centers, regional return centers, and a growing direct-to-consumer customer base. The company sells across six major product categories:

### Apparel

Apparel includes shirts, trousers, jackets, dresses, and seasonal fashion items. Return rates are high because customers order multiple sizes or styles. The inspection process is usually fast, but resale value falls quickly when promotional windows close or seasonal relevance declines.

Apparel returns can often be restocked as new if packaging and labels are intact. If inspection is delayed, items may move to outlet or liquidation even when their physical condition is good.

### Footwear

Footwear has similar size and fit issues, but inspection is slightly more involved because signs of use can be harder to judge. Return rates are high, and value recovery depends on fast grading and clean packaging.

Management suspects that some customers use free returns as a try-at-home service. Tightening the return policy could reduce volume, but it might also reduce conversion.

### Consumer Electronics

Consumer electronics include small appliances, smart-home devices, audio devices, and accessories. Return rates are lower than apparel, but inspection is slower and more expensive. Defect claims require technical checks, and delays can reduce resale value as product versions change.

Electronics create a different challenge: one delayed return may carry more financial impact than many low-value apparel items.

### Home Living

Home living includes decor, lamps, storage products, small furniture, and kitchenware. Items vary widely in size and handling effort. Damage in transit, missing parts, and packaging condition influence the recovery path.

The category creates pressure on return-center space because bulky items accumulate quickly during backlog periods.

### Sports and Outdoor

Sports and outdoor products include fitness equipment, camping accessories, and seasonal products. Demand and return timing are promotion-driven. Some items can be resold quickly, while others lose value rapidly after seasonal peaks.

### Beauty and Health

Beauty and health products have lower average item values, but stricter resale constraints. Many returns cannot be resold as new once opened. The financial issue is less about inspection speed and more about correct routing and policy design.

## The Trigger

In early 2026, LumaHome launched a growth plan built on free returns, faster refund promises, and aggressive seasonal promotions. Sales increased. Return volume increased faster.

By April, the return center network was under pressure:

- Backlog rose after promotional campaigns and month-end delivery waves.
- Refunds were paid before inspection in many cases, increasing manual-review and dispute risk.
- High-value electronics waited too long for technical checks.
- Apparel and footwear arrived in sellable condition but missed their best resale window.
- Outlet and liquidation shares increased, reducing recovery value.
- Customer service received complaints about slow refunds, while finance questioned the cost of generous return rules.

Operations argued that the company needed more inspection capacity. Finance argued that staffing alone would not fix return behavior or poor triage. Merchandising argued that some product pages and size recommendations were creating avoidable returns. Customer experience argued that strict return policies would damage trust.

Elena Hartmann asked an external student consulting team to answer one question:

> Where should LumaHome intervene first if it wants to reduce margin loss from returns without damaging customer experience?

## The Decision

LumaHome must decide how to change its returns process before the next seasonal campaign. Management can add temporary inspection capacity, create fast lanes, delay selected refunds until inspection, change product-page guidance, tighten abuse controls, improve refurbishment routing, or redesign remarketing priorities. It cannot solve every problem at once.

The student team must use the available data to build a defensible argument. A strong answer will not simply identify the product category with the highest return rate. It will distinguish between return propensity, item value, inspection effort, capacity bottlenecks, refund policy, resale decay, product quality, customer behavior, and data-quality noise.

## Management Constraints

LumaHome's leadership has set five constraints:

1. Customer experience may not be damaged without clear evidence of financial benefit.
2. Recommendations must be implementable before the next seasonal campaign.
3. Any proposed KPI must be understandable to operations, finance, merchandising, customer service, and sustainability.
4. The analysis must separate data-quality issues from return, inspection, and resale performance where possible.
5. The final presentation must be concise enough for a 15-minute management meeting.

## Data Available

Students receive several Excel workbooks covering the e-commerce returns process:

- Sales order-line records.
- Return authorization and parcel receipt records.
- Inspection and grading records.
- Refund transaction records.
- Resale and disposition records.
- Return-center capacity calendars.
- Product, return-center, fulfillment-center, customer-segment, carrier, cost, calendar, and policy reference tables.

Each split workbook contains:

- A main data sheet with operational records.
- Reference sheets with product, return-center, and customer-segment attributes where useful.
- An assumptions sheet describing generation logic and intended teaching caveats.
- A split-info sheet where applicable.

The company warns that not every record should be taken at face value. The data reflect order systems, return portals, warehouse scans, inspection workstations, payment systems, and resale platforms. They do not form a cleaned analytical table.
